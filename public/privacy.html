プライバシーポリシー

制定日: 2026年11月8日 ／ 最終更新: 2026年11月9日

結論: 本サービスは、利用者の画像・編集内容を収集しません。 画像が端末の外に送信されるのは、利用者が「Ollama」を選んで検出を実行し、 かつ送信先を自分の PC 以外に設定した場合だけです。

1. 収集しない情報

  • 画像データ（本サービスのサーバーには送信されません）
  • マスク範囲・編集内容・書き出した画像
  • Cookie、アクセス解析、広告識別子
  • 認証情報（本サービスに入力欄はありません）

2. 画像の処理場所

  • ブラウザ内（無通信・既定）: 顔も文字（OCR）も端末内で検出し、画像は端末から一歩も出ません。顔検出モデルも OCR のエンジン・辞書も本サービスと同じ配信元から読み込みます。
  • Ollama: 利用者が入力したエンドポイント（既定は http://localhost:11434）にのみ送信します。自分の PC で動かす限り、画像は PC の外に出ません。送信先を LAN の他の機器や外部サーバーにした場合は、その機器に画像が渡ります。

3. Ollama を外部で動かす場合

本サービスは Ollama の運営・提供元ではありません。利用者が指定したエンドポイントの管理者が定める 利用条件・ログの取扱いに従うものとし、本サービスは関与しません。

4. サーバーのアクセスログ

本サービスは静的ファイルを Amazon S3 / CloudFront から配信しています。配信基盤は、一般的なウェブアクセスと同様に、 IP アドレス・ユーザーエージェント・リクエスト URL などを運用ログとして記録する場合があります。 これらに画像の内容や編集内容は含まれません。ログは運用・不正アクセス対策の目的にのみ使用します。

5. 入力内容の取扱い

  • 本サービスに API キーなどの認証情報を入力する欄はありません。
  • Ollama のエンドポイントとモデル名はページのメモリ上にのみ保持し、リロードで消えます。
  • localStorage・Cookie・サーバーには保存しません。
  • 通信先は CSP により localhost（自分の PC）に制限しています。

6. 第三者提供

本サービスは、利用者の情報を第三者へ販売・提供しません。

7. お問い合わせ

本ポリシーに関するお問い合わせは GitHub Issues へお願いします。

8. 改定

本ポリシーを変更する場合は、本ページに掲載した時点で効力を生じます。
