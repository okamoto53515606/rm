プライバシーポリシー

制定日: 2026年11月8日

結論: 本サービスは、利用者の画像・API キー・編集内容を収集しません。 画像が外部に送信されるのは、利用者が「Gemini」または「Ollama」を選んで検出を実行したときだけです。

1. 収集しない情報

  • 画像データ（本サービスのサーバーには送信されません）
  • Gemini API キー（ブラウザのメモリ上にのみ存在し、保存も送信もしません）
  • マスク範囲・編集内容・書き出した画像
  • Cookie、アクセス解析、広告識別子

2. 画像の処理場所

  • ブラウザ内（無通信）: 顔も文字（OCR）も端末内で検出し、画像は端末から一歩も出ません。顔検出モデルも OCR のエンジン・辞書も本サービスと同じ配信元から読み込みます。
  • Gemini: 検出を実行したときだけ、長辺 1536px に縮小した JPEG を Google の Gemini API へ送信します。API キーはブラウザから Google へ直接送信され、本サービスのサーバーは関与しません。
  • Ollama: 利用者が入力したエンドポイント（通常は自分の PC）にのみ送信します。

3. 外部サービスにおける取扱い

Gemini API に送信されたデータは、Google の利用規約およびデータ取扱いポリシーに従って処理されます。 無料枠では入力がサービス改善に利用される場合があります。機密性の高い画像を扱う場合は、有料枠の利用や、 「ブラウザ内（無通信）」の利用を検討してください。

本サービスは Google の承認・提携を受けたものではなく、Gemini API を利用者自身のキーで呼び出すだけのツールです。

4. サーバーのアクセスログ

本サービスは静的ファイルを Amazon S3 / CloudFront から配信しています。配信基盤は、一般的なウェブアクセスと同様に、 IP アドレス・ユーザーエージェント・リクエスト URL などを運用ログとして記録する場合があります。 これらに画像の内容や編集内容は含まれません。ログは運用・不正アクセス対策の目的にのみ使用します。

5. API キーの管理

  • 入力された API キーはページのメモリ上にのみ保持し、リロードで消えます。
  • localStorage・Cookie・サーバーには保存しません。
  • キーは Google のエンドポイント以外へ送信しません（CSP により通信先を制限しています）。

6. 第三者提供

本サービスは、利用者の情報を第三者へ販売・提供しません。

7. お問い合わせ

本ポリシーに関するお問い合わせは GitHub Issues へお願いします。

8. 改定

本ポリシーを変更する場合は、本ページに掲載した時点で効力を生じます。
