    写真はこのブラウザの中だけで処理されます。

    待機中

    自動検出

    自動検出は 顔・ナンバープレート・APIキー・氏名/連絡先・ユーザー名/パス などを探します。文字の検出には Ollama、またはローカルOCRを使います。

    Ollama の顔の枠を、端末内の顔検出（478点）でぴったりに合わせ直します。初回のみ顔モデルを読み込みます。

    初回のみOCRデータ約18MB（顔モデルと合わせて約38MB）を読み込みます。1枚2〜4秒。APIキー・メール・パス・端末プロンプトを正規表現で探します。ナンバープレートは、写真の中の明るい四角を探してその部分を拡大し、番号が読めたときに隠します。

    Ollama の設定手順

    書き出し

    JPEG に統一し、位置情報などの EXIF は削除して書き出します。

    プライバシー
    • 画像が当サイトのサーバーに送られることはありません。
    • Ollama を使うときも、画像はこの PC（localhost）の中だけで処理されます。
    • API キーなどの入力項目はありません（保存も送信もしません）。
    • アクセス解析・Cookie・外部フォントは不使用です。

    AI の検出は 100% ではありません。公開前の目視確認をおすすめします。

    使い方と安全性

    1. 写真をドラッグ＆ドロップ（または Ctrl+V）で追加します。
    2. 「自動検出」で顔・ナンバープレート・機密文字列に加え、ターミナルのユーザー名・ホスト名・フォルダパスも候補として出します。API キーはどちらのモードでも不要です。「文字も検出（OCR）」にチェックすると、APIキーなども無通信で探せます。
    3. 枠をドラッグして位置と大きさを直します。四隅のハンドルでリサイズ、Delete で削除、Ctrl+Z で元に戻せます。
    4. 「隠し方」を変えると背景のプレビューにすぐ反映されます。仕上がりを見て、確認済みにチェックします。
    5. 「マスクして保存」で JPEG 書き出し（複数枚は ZIP）。

    データの行き先

    • ブラウザ内（無通信）: 顔も文字（OCR）も端末内で検出します。画像は端末から出ません。
    • Ollama: この PC の Ollama（localhost）にのみ送信します。通信先を CSP で localhost に限定しているため、外部には送信されません。

    できないこと・注意

    • AI の検出漏れはあります。確認済みチェックは「人が見た」印です。
    • HEIC は変換に対応していますが、端末やブラウザによっては失敗することがあります。
    • GIF は先頭フレームのみを読み込みます（アニメーションは保持されません）。
    • あまりに大量・高解像度の写真を一度に処理すると、ブラウザのメモリ不足で失敗することがあります。

    できること

    写真やスクリーンショットに写った顔・ナンバープレート・APIキーなどを、画像を外部に送信せず ブラウザ内で検出し、モザイク・ぼかし・黒塗りで隠せる無料のツールです。書き出した JPEG からは EXIF（GPS・撮影日時・機種名）も削除します。

    • 顔とナンバープレートの自動検出（端末内の AI）
    • スクリーンショットの API キー・トークン・パスワード・秘密鍵・メールアドレス・IP アドレス・ローカルパス・端末プロンプトの検出（ローカル OCR）
    • 矩形・楕円・多角形の手動マスク（移動・リサイズ・取り消し）
    • 隠し方: モザイク＋ぼかし / モザイク / ぼかし / 黒塗り
    • 複数枚の一括処理・ZIP 書き出し・EXIF 削除

    スクリーンショットの API キーを隠すには

    「文字も検出（OCR）」をオンにして検出すると、API キーやトークンらしい文字列の行が枠で示されます。 枠を確認し、黒塗りを選んで保存すれば、画像をどこにも送信せずに隠せます。

    写真の顔・ナンバープレートを隠すには

    ブラウザ内の顔検出（478 ランドマーク）が顔を、プレート検出がナンバープレートを枠で示します。 集合写真では小さい顔を分割して再検出します。検出した枠はドラッグで移動でき、四隅のハンドルで大きさを変えられます。

    画像はサーバーに送られますか

    送られません。検出もマスクも書き出しもブラウザ内（WebAssembly）で完結し、画像が当サイトのサーバーを 通ることはありません。通信先は CloudFront の CSP（connect-src）で localhost に限定しており、 外部サーバーへ送信することは技術的にできません。アクセス解析・Cookie・外部フォント・外部 CDN も使っていません。

    EXIF（GPS）は残りますか

    残りません。書き出しは Canvas で JPEG を作り直すため、撮影場所・撮影日時・機種名は含まれません。 実測では GPS 付き JPEG の exif=true, gps=true が、書き出し後に exif=false, gps=false になります。

    スマートフォンでも使えますか

    現在は PC のブラウザを想定しています。大きな写真とローカル AI（初回で約 38MB）を扱うためで、 スマートフォンでの動作は保証していません。スマートフォンから試す場合は、まず 1 枚だけでお試しください。

    検出精度と処理時間

    自動検出は 100% ではありません。合成画像と実写真 14 枚・正解 25 個の評価で、再現率 96%・適合率 100% でした。 処理時間は顔が約 0.3 秒、文字検出込みで 1 枚 0.5〜2 秒（4000px 級は 2 秒前後）です。

    小さい・傾いたナンバープレート、強いぼけ、夜間の白飛びなどは検出できないことがあります。 自動検出に頼らず、手動の矩形も併用してください。

    よくある質問

    無料で使えますか？

    無料です。MIT ライセンスでソースコードも公開しています。

    会員登録やインストールは必要ですか？

    不要です。ページを開いて画像を選ぶだけで使えます。

    対応している画像形式は？

    JPEG・PNG・WebP・GIF（先頭フレーム）・BMP・AVIF・HEIC を読み込めます。書き出しは JPEG、複数枚のときは ZIP です。

    オフラインでも使えますか？

    一度読み込んだ後は、ブラウザ内（無通信）モードでオフラインでも動作します。

    検出漏れはありますか？

    あります。AI の検出は 100% ではないため、確認済みにチェックせず書き出そうとすると警告を表示します。
